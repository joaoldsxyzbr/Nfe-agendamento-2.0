# NFe Agendamento 2.0 — v0.0.17

Release de estabilização e hardening acumulado após a v0.0.16.

## Principais mudanças

- limite operacional de 100 NF-e válidas por lote, com tratamento de erro mais explícito e orçamento de memória para ZIP;
- geração de ZIP sem buffer final monolítico duplicado;
- rate limit do Worker separado por finalidade, com coordenação fiscal por IP e proteção específica da rota de atualização;
- cache curto da metadata de atualização para reduzir chamadas repetidas ao upstream;
- updater preservando validação de origem, versão, tamanho e SHA-256 sem tornar Authenticode obrigatório;
- ciclo do visualizador DANFE consolidado, com focus trap, retorno de foco e cobertura de teclado/backdrop;
- hardening adicional do helper Portal, incluindo limpeza de XML temporário antigo e validações de segurança;
- E2E em Chromium para consulta unitária e estados da interface;
- cobertura V8 do frontend/Worker registrada no CI;
- workflows e ações de terceiros pinados por SHA imutável;
- documentação de arquitetura, operação e aceitação sincronizada com o estado atual.

## Arquitetura

Permanece a arquitetura v2:

- site Cloudflare;
- Worker/Durable Object para coordenação;
- App + Bridge local por computador;
- certificado A1 somente no Windows local;
- Portal/WebView2 apenas como fallback legítimo, com hCaptcha manual;
- sem Central, pareamento, LAN, mDNS ou pasta compartilhada.

## Validação automatizada

A release só é publicada quando o mesmo commit conclui com sucesso:

- `web`;
- `danfe-print`;
- `bridge`;
- `fiscal-compatibility`;
- `windows-package`.

CodeQL também deve permanecer verde no SHA final.

## Controles opcionais

Authenticode e branch protection/ruleset continuam opcionais por decisão do projeto. A ausência desses controles não bloqueia CI, atualização nem release.

## Validação física

A validação Windows/A1/SEFAZ/Portal continua separada do CI. Ela é necessária somente para declarar o comportamento do ambiente real como fisicamente validado.

O commit marcador desta release deve usar exatamente:

```text
release: v0.0.17
```
