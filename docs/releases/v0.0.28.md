# NFe Agendamento 2.0 — v0.0.28

Release de teste que restaura a estratégia fiscal do antigo Bridge mantendo a arquitetura **site + extensão**.

## Extensão 0.2.6

- consulta `NFeDistribuicaoDFe` primeiro;
- Portal Nacional somente como fallback;
- CNPJ do A1 configurado uma vez e armazenado localmente;
- proteção local de 20 consultas diretas/hora;
- cooldown de 1 hora para 656/429/limite local;
- 217 usa Portal somente para a NF-e afetada;
- no lote, limite de consumo move os itens restantes para Portal;
- erros de transporte não fazem retry automático;
- nenhuma volta do Bridge, EXE ou Native Messaging.

## Gate físico

Esta versão exige teste real no Windows para confirmar a negociação do certificado A1 pelo Chrome/Edge na chamada direta ao endpoint da SEFAZ. Os testes automatizados não substituem esse gate.
