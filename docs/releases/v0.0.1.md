# NFe Agendamento 2.0 — v0.0.1

Primeira release do novo fluxo **site + Bridge Windows mínimo**.

## Incluído

- consulta individual de NF-e pelo site usando o certificado A1 do computador;
- Bridge local restrito a `127.0.0.1:17345` e API `/api/v1`;
- seleção do certificado A1 pelo painel de configurações aberto pela engrenagem no canto superior direito;
- consulta SEFAZ `NFeDistribuicaoDFe` sem retry automático em respostas ambíguas;
- validação e parsing do XML no navegador;
- tratamento Fernando Klein preservando o `cProd` fiscal original;
- DANFE A4 com preview, Ctrl + scroll e impressão/PDF;
- fallback integrado para limite/656 via Portal Nacional e WebView2, com hCaptcha sempre manual;
- tema dark azul e amarelo inspirado no site legado;
- pacote Windows com `NfeAgendamento.Bridge.exe` e `NfeAgendamento.Portal.exe` lado a lado.

## Requisitos no Windows

- .NET 10 Desktop Runtime;
- Microsoft Edge WebView2 Runtime;
- certificado A1 instalado no repositório `CurrentUser/My`;
- origem HTTPS exata do site configurada em `Bridge:AllowedOrigins` antes de iniciar o Bridge.

Exemplo:

```powershell
$env:Bridge__AllowedOrigins__0 = "https://SEU-DOMINIO-EXATO"
.\NfeAgendamento.Bridge.exe
```

## Validação

A release é criada somente após o CI validar testes/build web, Bridge, helper WebView2 e geração do pacote Windows.

O teste físico com certificado A1 real, consulta SEFAZ real e ocorrência de fallback 656 continua sendo o gate de aceitação em ambiente Windows antes de considerar a versão validada para produção.
