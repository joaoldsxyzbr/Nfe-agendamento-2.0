# NFe Agendamento 2.0 — v0.0.32

Patch somente do site para fechar estados residuais do preflight fiscal.

## Correções

- restaura ZIP e impressão de resultados já concluídos quando um novo preflight termina sem iniciar lote;
- re-renderiza as ações dos itens depois que o lock do preflight é liberado;
- bloqueia **Tentar pelo Portal** enquanto o preflight está em andamento;
- impede reconsulta Portal antiga de rodar em paralelo com o início de um novo lote.

## Extensão

A extensão permanece **0.2.9**. Não há mudança no binário da extensão nem no fluxo fiscal.

## Fluxo fiscal

Permanece:

- SEFAZ primeiro;
- 138 + XML conclui direto;
- 217 usa Portal somente para o item atual;
- 656/429/proteção local encaminham para Portal;
- sem retry fiscal automático;
- hCaptcha manual;
- sem Bridge.
