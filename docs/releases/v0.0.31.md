# NFe Agendamento 2.0 — v0.0.31

Patch de robustez do preflight fiscal da v0.0.30.

## Correções

- bloqueia o lote já no início do preflight, antes de aguardar o handshake da extensão;
- impede duplo clique de iniciar loops paralelos ou consultas SEFAZ duplicadas;
- libera o lock corretamente quando o preflight termina sem iniciar o lote;
- a extensão 0.2.9 anuncia explicitamente suporte a abertura automática das opções;
- mantém compatibilidade com a 0.2.8, que já possuía o comando mas não anunciava a capability;
- extensão 0.2.7 ou anterior não recebe mensagem falsa de que a configuração foi aberta: o site orienta atualização ou abertura manual.

## Fluxo fiscal

Sem alteração:

- SEFAZ / NFeDistribuicaoDFe primeiro;
- 138 + XML conclui diretamente;
- 217 usa Portal somente para a NF-e atual;
- 656/429/proteção local encaminham para Portal;
- sem retry fiscal automático;
- hCaptcha manual;
- sem Bridge.
