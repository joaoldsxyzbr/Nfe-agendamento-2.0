# NFe Agendamento — extensão independente v0.3.0 (PILOTO)

**Pré-lançamento experimental — NÃO é versão estável e NÃO substitui a edição oficial.**

Este pacote reúne o NFe Agendamento em uma única extensão Manifest V3 para **Chrome/Edge desktop**, sem dependência do site Cloudflare, Workers ou D1 para executar a interface. A consulta fiscal continua dependendo de conexão com o **Portal Nacional da NF-e**. **hCaptcha permanece manual** e o certificado digital é tratado pelo navegador quando exigido.

## Download e instalação

Baixe o arquivo **NFeAgendamento-Extension-Piloto-v0.3.0.zip** nos Assets desta release (não use "Source code ZIP"). Extraia o conteúdo e abra **chrome://extensions** ou **edge://extensions** → Modo do desenvolvedor → **Carregar sem compactação** → selecione a pasta extraída que contém `manifest.json`. Clique no ícone da extensão para abrir o sistema.

**Use um perfil separado**, para não misturar o piloto à extensão oficial.

## Avisos importantes

- **Aceitação física: NÃO EXECUTADA** para Chrome/Edge com Portal, certificado, XML real, DANFE, lote e cancelamento.
- **CI completo da PR experimental ainda apresentou falhas** em jobs web/auditoria de dependências; o workflow deste pré-lançamento valida especificamente os testes, a cobertura, o build e o pacote da extensão, além de auditar dependências de runtime.
- Sem garantia de funcionamento com notas fiscais reais. Use apenas para avaliação controlada.
- A `main`, releases estáveis existentes e o serviço Cloudflare vigente não foram alterados nem desligados.
- A captura XML permanece no Portal oficial, sem contorno de hCaptcha e sem consulta direta à SEFAZ.
